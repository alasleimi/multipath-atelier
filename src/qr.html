WHY AN UNORDERED REPRESENTATION?

Paths are a set. References are a set.

Shared path transforms and symmetric pooling remove dependence on path order. With fixed latent codes, reordering references only reorders the softmax and weighted-sum terms. Nearest-delay ties use deterministic preprocessing.

The September protocol retains up to nine paths; masking and pooling can handle other path counts. All-path results require a separately trained and evaluated protocol.

WHERE MULTIMODALITY ENTERS

Several hypotheses ≠ a mode selector.

QR-S can generate alternative global predictions, but 32 draws do not guarantee 32 distinct modes or a calibrated posterior. The deployed mean can fall between lobes.

The core model does not cluster lobes, select the best one using truth, or fuse QR-S with QR-D. Each variant is a separately trained, independently deployed network.

Training is a separate lane

Known training coordinates supervise the deployed mean, pair displacements, predicted separations and proximity-based similarity. QR-S also uses best-of-K global supervision (K = 8 during training); QR-D uses one zero code and omits the global best-of-K term.

The September NIST protocol additionally uses survey-fitted range surfaces to synthesize continuous training fingerprints. This is an offline augmentation choice, not access to simulator geometry at inference; its simulator-specific bias needs separate controls.

Held-out query truth is used only for evaluation. It does not choose a hypothesis or a reference at deployment.

ρ is predicted normalized physical separation, not a measured query-to-reference distance. Δ, b and C are learned heads. The two coordinate corrections in this core are unrestricted Cartesian outputs.

Training loss: mean-location error + 0.3 × best-global error + 0.2 × best-pair error + 0.3 × (distance loss + 0.05 × similarity loss). The best-global term is zero-weighted in QR-D.
